# Roadmap

Ideas for taking Peep & Post beyond the No4. Tick items off as they land.

## Rifles and sights
- [ ] Rifle profiles, so one install can hold several rifles, each with its own sight, blade, ammunition and firings
- [ ] SMLE No1 Mk III (ladder and volley sights; 1914 pattern sights)
- [ ] No4 Mk2 and No5 jungle carbine
- [ ] P14 / M1917, Mauser K98k, Mosin-Nagant, Springfield 1903, M1 Garand, Swiss K31, Lebel / Berthier
- [ ] Sight library: each sight's graduations, click value, battle setting and whether it is graduated in yards or metres

## Calibres and ammunition
- [ ] Calibre library (.303 British, 8x57, 7.62x54R, .30-06, 7.5x55 Swiss, 6.5x55, .308 / 7.62 NATO…)
- [ ] More factory loads per calibre, plus hand-loads with chronographed velocity
- [ ] Truing: work out a load's real velocity or BC from long-range groups
- [ ] Metric option for ranges and sight scales

## Features
- [ ] Wind: record wind with each group and give aim-off tables
- [ ] Session view: a day at the range with weather, then the groups shot
- [ ] Printable range card (A6 or pocket size)
- [ ] Shot plotting: tap shots onto a picture of the target and work out group centre and size automatically
- [ ] Export and import a whole sight book as a file to share with club members
- [ ] Optional Android app package (.apk) built from the hosted app
